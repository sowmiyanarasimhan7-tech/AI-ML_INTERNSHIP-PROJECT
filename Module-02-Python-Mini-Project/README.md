# Module 02 – Python Mini Project

Python mini project for Module 02 (Day 5–Day 8).

## Learning objectives
- Apply Python fundamentals to build a practical application.
- Accept, validate, and process user input.
- Use conditions, loops, functions, and dictionaries.
- Perform calculations and display formatted results.
- Practise problem-solving and debugging.

## Project: Student Grade Calculator
A command-line Python program that collects a student's name and marks in five subjects, calculates the total and average, assigns a grade, and displays the result.

## Project features
- Accepts a student name.
- Collects marks for Python, Mathematics, Computer Science, English, and Data Science.
- Validates that each mark is between 0 and 100.
- Calculates total marks and average percentage.
- Assigns a grade and displays a result status.

## Concepts used
- Variables and data types
- Input and output
- Arithmetic operations
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Functions
- Lists and dictionaries
- Exception handling (`try` and `except`)

## Repository contents

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run `python main.py`.
4. On Windows, you can also run `py main.py`.
5. Enter the student name and marks when prompted.
