# Module 01 – Introduction to AI & Python

Beginner learning repository for Module 01 (Day 1–Day 4).

## Learning objectives
- Understand Artificial Intelligence, Machine Learning, and Deep Learning.
- Explore real-world applications of AI.
- Learn Python basics: variables, data types, input/output, conditions, loops, functions, and lists.
- Write and run beginner-friendly Python programs.

## Repository contents
- `learning_notes.md` – complete learning notes.
- `programs/` – Python practice programs.

## How to run
1. Install Python 3.
2. Open a terminal in this repository.
3. Run a program, for example:

   ```bash
   python programs/01_add_two_numbers.py
   ```

   On Windows, you can also use `py programs/01_add_two_numbers.py`.

## Programs
1. Add two numbers
2. Check even or odd
3. Find the largest of three numbers
4. Sum numbers from 1 to n
5. Square using a function
6. Average of list values
